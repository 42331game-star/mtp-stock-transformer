# 04 · 回測與交易規則（Backtest & Execution）

> 本文件對應程式碼：`mtp/config.py`（門檻參數）、`mtp/cli/backtest.py`（模擬引擎）

## 1. 為什麼門檻這麼高？

模型的預測準確率不是重點，**扣完成本還剩多少**才是。
台股一個來回的成本約：

| 項目 | 費率 | 說明 |
|---|---|---|
| 手續費（買 + 賣） | 0.05% × 2 = 0.10% | 券商折讓前 |
| 證券交易稅（賣出） | 0.30% | 台股；美股僅 0.03%（`tax_rate=0.0003`） |
| **合計** | **≈ 0.40%** | 一進一出固定摩擦 |

因此設定 `cost_cover_ratio = 5.0`：
**T+10 預估利潤必須 ≥ 0.40% × 5 = 2.0%**，才允許進場。
（實作中同時要求 T+10 ≥ 4.5%，為雙重保險）

## 2. 訊號條件（Path Resonance，多步軌跡共振）

```python
d5  >= 2.5%          # T+5 預估報酬
d10 >= 4.5%          # T+10 預估報酬
d3  >  -1.0%         # 短線不能已經破位
d10 >= 5 × 0.40%     # 利潤覆蓋摩擦成本 5 倍
d1  >  -15%          # 排除明顯的崩跌型（資料異常）
```

四個條件**同時成立**才進場，這就是 MTP 的核心價值：
單頭預測容易被雜訊騙，但 T+3 / T+5 / T+10 必須**方向一致**才出手，
等於讓模型自己做「路徑確認」，進場次數大幅下降、單筆品質提升。

## 3. 出場規則

### 3.1 ATR 追蹤停損（2.3×ATR）
```
停損線 = 持有期間最高價 − 2.3 × ATR(14)
```
- 進場當天以「進場價 − 2.3×ATR」為起始停損
- 每天用當日最高價更新追蹤線
- 當日最低價跌破追蹤線 → 以**追蹤線價格**成交（保守估價）

2.3 倍的由來：ATR(14) 約為日波動，2.3 倍約略涵蓋 95% 的日內噪音，
避免被正常震盪掃出，同時在真正反轉時截斷虧損。

> ⚠️ 同一根 K 棒的處理是簡化的：程式**先**用當日 high 拉高追蹤線、
> **再**檢查當日 low 是否觸發。真實情況無法知道日內高低點的先後順序；
> 加上跳空穿越停損線時仍以停損線價格成交（實際會更差），
> 這兩點都讓停損結果帶有不確定性，方向不一定是樂觀。

### 3.2 時間出場
持倉滿 `horizon_days = 10` 個交易日 → 平倉。

> 📌 `mtp/config.py` 有 `extension_thresh` 參數，README 與本文件過去也描述過
> 「路徑夠強可續抱到 30 天」的展延規則，但**目前回測並未實作展延**，
> 持倉一律在 10 個交易日平倉。要實作請加進 `mtp/cli/backtest.py` 的出場迴圈。

### 3.3 部位管理（建議做法，回測未實作）
以下為實戰建議，**`mtp/cli/backtest.py` 目前沒有實作任何部位限制**：

- 5 個槽位，每槽 20% 資金（或 2x 槓桿 → 40% 曝險）
- 新訊號僅在有空槽時進場
- 每日重算預測，更新追蹤停損線

回測的實際行為是：每個交易日只要訊號成立就記一筆交易，
**不同訊號的持倉期間可以任意重疊**，沒有資金上限、沒有槽位、沒有複利再平衡。

## 4. 回測設計重點

| 項目 | 處理 |
|---|---|
| 前置檢查 | 先跑 `mtp-evaluate`（＝ `python scripts/evaluate.py`），確認模型在測試期真的勝過 zero baseline |
| 評估區間 | **全域 test 切分**（pooled dates 的後 15%，含 10 天 embargo，與訓練標籤零重疊）；切分日取自 `<checkpoint>.json` sidecar |
| 成本 | 毛報酬逐筆扣除手續費 + 交易稅（`net_return`） |
| 成交假設 | 以訊號日收盤價進場、以追蹤線 / 收盤價出場 |
| 投組淨值 | 同日進場交易取「平均報酬」÷「平均持有天數」→ 日報酬 → 累乘淨值 |
| 基準 | 同期 Buy & Hold 均值、SPY（`--no-benchmark` 可跳過網路抓取） |
| 重點檢視 | 2022 年單邊熊市的年度報酬與最大回撤 |

> 關於「投組淨值」那一列：它是一種**近似**，不是逐筆複利的帳戶曲線。
> 同一天多筆訊號取平均（等權）、把一筆 10 天的報酬除以平均持有天數當日報酬、
> 忽略重疊持倉的資金占用。Sharpe 與 MDD 都建立在這個近似上。

```bash
# 台股（含 0.3% 交易稅）
mtp-backtest

# 美股（交易稅改為 0.0003）
mtp-backtest --tax-rate 0.0003 --data-dir ./data/market_large

# 離線（不抓 SPY）
mtp-backtest --no-benchmark

# 未安裝套件時的等價寫法
python scripts/backtest.py --no-benchmark
```

## 5. 必須知道的回測限制

1. **先看 `evaluate.py`，再看這裡的數字。** 若模型在測試期的 Huber 不比
   「永遠預測 0」低、或 |IC| 的 t < 2，那這裡的績效反映的是門檻參數
   （2.5% / 4.5% / 2.3×ATR），不是模型的預測力。
2. **參數是在歷史資料上選的**，存在間接過擬合風險。
3. **成交假設樂觀**：以追蹤線價格成交，實際跳空可能更差；未模擬滑價與流動性限制。
4. **進場價不可執行**：訊號要當日收盤才算得出來，卻以當日收盤價成交，
   實務上最早只能在隔日進場，會吃掉一部分預期獲利。
5. **同一根 K 棒的停損順序被簡化**（先更新高點、再測試低點），且跳空不重定價。
6. **等權重、無複利再平衡、無部位上限**：投組淨值由單筆均值近似，
   重疊持倉的資金占用沒有被計算，與真實帳戶有落差。
7. **樣本高度重疊**：訊號以 stride=1 逐日產生，相鄰視窗重疊 249/250 天，
   交易序列也非獨立，勝率與 Sharpe 的顯著性被高估。
8. **市場體質重疊與倖存者偏差**：訓練期與回測期同屬 2015+ 的牛市為主環境，
   標的又是刻意挑選的存續大型股／ETF，對未見過的體質（2008、2020 崩盤）缺乏保證。
9. **依賴資料快照**：切分日由當下的資料決定，重新下載會移動邊界；
   請用與訓練同一份資料評分（sidecar 會優先採用訓練時記錄的邊界）。
10. **非投資建議**：本專案為教學 / 研究用途。

## 6. 建議的後續驗證

- [ ] **通過 skill 檢驗**：`mtp-evaluate` 顯示模型穩定勝過 zero /
      momentum baseline，且 |IC| 的 t ≥ 2
- [ ] **Walk-forward 滾動訓練**：每季重訓、只在之後的區間評估
- [ ] **多市場驗證**：同一模型套用台股 `market_tw`，比較泛化能力
- [ ] **參數敏感度**：門檻 ±0.5%、ATR 倍數 ±0.5 的績效穩健性（穩定才是真本事）
- [ ] **蒙地卡羅 / bootstrap**：重抽交易序列，觀察報酬分配與破產機率
- [ ] **公開的樣本外**：留存 2026 年之後的資料完全不碰，做最終驗證
