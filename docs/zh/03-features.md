# 03 · 特徵工程（16 維輸入因子）

> 本文件對應程式碼：`mtp/features.py`
> **訓練、回測、即時推論三個環節共用同一份實作**，確保特徵定義不會漂移。

## 特徵一覽

| # | 特徵 | 公式 | 意義 |
|---|---|---|---|
| 1 | `ret_1d` | `ln(C_t / C_{t-1})` | 短線動能 / 日報酬 |
| 2 | `ret_5d` | `ln(C_t / C_{t-5})` | 週線動能 |
| 3 | `ret_20d` | `ln(C_t / C_{t-20})` | 月線趨勢 |
| 4 | `hl_ratio` | `(H - L) / C` | 日內振幅（波動體質） |
| 5 | `vol_change` | `ln(V_t+1 / V_{t-1}+1)` | 成交量突變（量能表態） |
| 6 | `bias_5` | `(C - MA5) / C` | 5 日均線乖離 |
| 7 | `bias_20` | `(C - MA20) / C` | 20 日均線乖離 |
| 8 | `bias_60` | `(C - MA60) / C` | 季線乖離 |
| 9 | `bias_120` | `(C - MA120) / C` | 半年線乖離 |
| 10 | `bias_240` | `(C - MA240) / C` | 年線乖離（牛熊分界） |
| 11 | `atr_norm` | `ATR14 / C` | 正規化真實波幅（停損距離基準） |
| 12 | `bb_width` | `4σ20 / C` | 布林通道寬度（收斂=變盤訊號） |
| 13 | `bb_pct_b` | `(C - (MA-2σ)) / 4σ` | 通道內相對位置 0~1 |
| 14 | `rsi_norm` | `RSI14/100 - 0.5` | 動量指標，中心化到 [-0.5, 0.5] |
| 15 | `vol_ma20_ratio` | `V / MA20(V)` | 相對量（今日量 vs 20 日均量） |
| 16 | `upper_shadow` | `(H - max(O,C)) / C` | 上影線（拉回 / 壓力） |

## 設計原則

### 1. 全部「無量綱」化
所有特徵都除以 `close` 或用比率表示，因此不同股價（$5 與 $5000）、
不同市場（台股、美股）可以用同一組權重。這是跨市場遷移的關鍵。

### 2. 五類資訊互補
```
報酬動能 (1-3)  ──── 方向
波動體質 (4,11-13) ── 風險（決定停損距離與是否該進場）
均線乖離 (6-10)  ──── 趨勢位置（是否過熱 / 超跌）
量能     (5,15)  ──── 確認（價格動能是否有量能支持）
型態     (16)     ──── 日內結構
```

### 3. 為何要 `dropna` 之後才切分？
`bias_240` 需要 240 個交易日暖機，若不先丟棄 NaN 再切分，
切分點之前的統計量會被 NaN 污染。

### 4. RSI 重新中心化
`(100 - 100/(1+RS))/100 - 0.5` 讓 RSI 落在 `[-0.5, 0.5]`，
中點 0 對應 RSI=50（多空平衡），對神經網路的輸入分布更友善。

### 5. 標準化：視窗內 z-score

```python
# 單一視窗
mean = feats.mean(axis=0)      # 只用這 250 天
std  = feats.std(axis=0) + 1e-7
feats = (feats - mean) / std
```

- 訓練 / 回測：走批次版 `mtp.features.standardize_windows()`（`[n, 250, 16]`，
  每列各自算 mean/std）
- 推論：走單視窗版 `standardize()`（`[250, 16]`）
- 兩者數學上完全等價，`tests/test_smoke.py` 有斷言它們逐列一致
- **不使用**全資料集統計量，避免依賴未來資料

> 曾經的 bug：訓練與回測用「整段序列」的統計量、推論用「視窗內」統計量，
> 三條路徑不一致。現在統一由 `standardize_windows` / `standardize` 提供，
> 並有 `tests/test_split.py::test_scaling_is_window_local_not_series_local` 鎖住。

> 新增特徵時，務必同步更新 `FEATURE_COLS` 順序並重新訓練；
> 權重檔與特徵順序是綁定的（`input_dim` 預設就是 `len(FEATURE_COLS)`，
> 與 `MTPConfig.input_dim` 自動一致）。

## 擴充建議

想加入的基本面 / 替代性因子（需自行取得資料）：
- **籌碼**：三大法人買賣超、融資融券餘額
- **評價**：本益比、股價淨值比、營收年增率
- **市場環境**：VIX、殖利率斜率、美元指數（需加入跨標的特徵）

加入方式：在 `features.py` 的 `add_features()` 末尾追加欄位，再把欄位名加入 `FEATURE_COLS`。
`MTPConfig.input_dim` 的預設值就是 `len(FEATURE_COLS)`，會自動跟著更新。
